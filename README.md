# CLblox

A simple Android launcher for Roblox.

- Save your favorite games and launch them with one tap (opens the official Roblox app via deep link)
- Performance helpers: Game Mode shortcut, Do Not Disturb, high refresh rate, thermal info
- Does NOT modify the Roblox app or its files, and contains no cheats or mods
